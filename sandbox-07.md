## Завдання 2. Скільки разів рахує Фібоначчі

### Передбачте

| Мій прогноз | Справжній вивід | Чому так |
|---|---|---|
| fib(10) = 55, calls = 11 | fib(10) = 55, calls = 177 | Рекурсивна функція викликає сама себе двічі, тому кількість викликів швидко зростає |

### Зміни одне

Замінила fib(10) на fib(20)

| Мій прогноз | Справжній вивід | Чому так |
|---|---|---|
| fib(20) = 177, calls = 21891 | fib(20) = 6765, calls = 21891 | 177 — це кількість викликів для fib(10), а fib(20) дорівнює 6765 |

### Напишіть самі

Написано програму для обчислення чисел Фібоначчі без рекурсії. Для цього використовуються два допоміжні числа та цикл for

Результат виконання:
55
102334155

Пояснення: ітеративний спосіб дозволяє обчислювати числа Фібоначчі без повторного виконання однакових обчислень, тому він ефективніший за звичайну рекурсію
